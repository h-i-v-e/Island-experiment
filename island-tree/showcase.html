  1. Botanical recipe

    A versioned, bounded value type captures species, scale and organ counts. The same seed and recipe reproduce the same specimen.

  2. Species growth program

    Six tailored programs cover coastal canopy, palm, fan, brush, emergent conifer and pendulous conifer forms.

  3. Shared prototype

    Axes, leaf organs, shoots, reproductive structures, bark state and generated maps cross the crate boundary without Bevy entity coupling.

  4. Bevy compilation

    The studio compiles bounded meshes and shared materials, applies LOD and wind, then supports interactive inspection and offline capture.

  5. Landscape population

    The next step is biome-aware placement, batching and distance transitions across the island—not another round of hand-authored assets.
