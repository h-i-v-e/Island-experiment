# TerraNullus boat test scenes

The TerraNullus project is outside this Git repository. This directory preserves the authored source for its boat-testing setup without redistributing Synty meshes, textures or baked geometry.

Copy the contents of `Assets/BoatTesting` into the same directory in TerraNullus, preserving `.meta` files. This needs the existing TerraNullus Player prefab, FloatingShip and PlayerController scripts, Synty Polygon Pirates assets, and the locally referenced Motu runtime/editor/sample packages.

After Unity compiles, choose **Island > Boat Tests > Create Test Scenes**. It generates:

- `Assets/Scenes/BoatTestbed.unity`: sea, sky and the real player; starts in inspection flight.
- `Assets/Scenes/RowingBoatTest.unity`: the first scene with a floating, boardable Synty rowing boat and four attached oars.
- Dedicated wave/environment assets, a rowing-boat wrapper prefab, baked hull sections and water-exclusion geometry under `Assets/BoatTesting`.

The generator creates scenes additively, saves only the generated scenes, then restores the previously active scene. It refuses to replace existing test scenes or the boat prefab. It does not alter build settings or Synty source assets.

Use **Validate Test Scenes**, **Run Rowing Boat Play Check** and **Run Empty Testbed Play Check** in the same menu. Play checks use Unity's start-scene override, then restore the previous editing scenes and start-scene setting.

Controls and setup details are in the included `Assets/BoatTesting/README.md`. This scene tests flotation, walking, boarding, seated IK and crewed rowing propulsion.

Oar rigs now expose **Blade Dip Degrees** (12 by default), pitching the blade down around its shaft pin while the hands follow the raised grips. Grip rotations describe wrist bones; BoatBoarding converts them to the avatar's fixed humanoid IK goal axes, retaining the conversion through strokes to avoid rotation drift. This follows [Unity's IK goal rotation conventions](https://docs.unity.com/en-us/engine/6000.5/script-reference/unityengine/animator/setikrotation). **Calibrate Rowboat Grips And Blade Dip** fits grip rotations to the idle rowing pose using the current authored oar and rowlock geometry; it preserves positions and model rotations and leaves scene changes unsaved. **Run Current Crewed Boat Oar Fit Play Check** measures immersion, pin error, hand position and wrist orientation in the current scene, including unsaved overrides. Live measurements with the user's revised scene found 0.00 mm pin/hand error, maximum wrist error 2.88 degrees, and blade-tip entry of 0.30–0.62 m below sampled water during forward strokes. The check allows five degrees for the residual wrist rotation introduced by humanoid retargeting. Runtime and editor sources also compile using Unity's compiler and existing assembly response files.

Grounded boat pushing uses **E / Interact** before ordinary boarding when the player is outside a slow grounded boat. Climbing aboard (including direct boarding requests) is disabled while the rowboat is grounded or beach-held, including when its streamed shore collider unloads. Boarding approaches and entry animations cancel if the boat grounds; seated occupants can still exit. After a successful push launch, the pushing player is automatically placed in the rowboat control seat via normal seat reservation and seated animation. A continuous .15 s afloat check follows the existing .2 s shore-contact grace, with actual water immersion required; the final shove is watched for up to 10 s after the clip ends. E, movement, jump, disable or another boarding action cancels that pending transfer; missed pushes never arm it, and occupied control seats are not taken over. Ordinary boarding becomes available again after launching. Walk close and face the hull, then press E: `PushOutBoat` plays immediately from the current position. There are no authored standing spots, hand targets, automatic approach or attachment to the boat. `BoatPushing` sweeps the animated palms against the actual wooden hull; each touching hand gets a small IK correction and supplies its own inward horizontal force at that surface point. Off-centre contacts turn the boat naturally. The solved palm must remain within 8 cm of that point, and an unreachable hand, missed hull or stale contact supplies no force. Hands release when withdrawing or out of reach; walk closer before another push if the boat moves away. E, movement, jump or loss of ground support cancels. A beached boat's hold releases only when a hand actually supplies force and can settle again afterward. `BoatPushable` retains editable force and speed settings. Copy `BoatPushing`, `BoatPushable`, their editor tools and the updated `RowboatController`; apply `boat-push-player.patch`, then run **Set Up Grounded Boat Pushing** (already applied in TerraNullus). Setup removes the former `Push spots` group, wires the actual hull colliders, and retains the user's push trigger and clip. `BoatPushPlayValidation.RunBatch` runs in the marked isolated project with real E input, arbitrary port/starboard/oblique/stern positions, palm IK measurements, a distant-hand miss case, and E/movement cancellation; no standing markers are used. Contact screenshot: `/tmp/boat-palm-contact.png`; measurements: `/tmp/boat-push-play.txt`.
