# Island experiment

Procedural free-form island generation and its scene-based Unity integration.

- [`island-rs`](island-rs/) contains the Rust generator, C ABI, tests, and the
  detailed coastal-erosion implementation plan.
- [`island-unity`](island-unity/) contains the reusable Unity 6
  `IslandGenerator` component, sandbox level, streamed terrain LODs,
  first-person sample controls, and the Apple Silicon native plugin.

See each project README for build and usage instructions.
