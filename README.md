# Island experiment

Procedural free-form island generation and its minimal Unity viewer.

- [`island-rs`](island-rs/) contains the Rust generator, C ABI, tests, and the
  detailed coastal-erosion implementation plan.
- [`island-unity`](island-unity/) contains the Unity 6 viewer, streamed terrain
  LODs, first-person mode, and the Apple Silicon native plugin.

See each project README for build and usage instructions.
